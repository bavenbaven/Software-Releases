# ERS TECH 电商平台

专业电商管理工具，一站式管理 TikTok Shop & Shopee。

## 软件下载

### 桌面端 (推荐)

| 版本 | 文件 | 大小 | 说明 |
|------|------|------|------|

### Web管理后台

访问: https://app.ers-tech.net

## 功能特性

- 🛒 **商品管理** - 批量上架商品到 TikTok Shop 和 Shopee
- 📦 **库存同步** - 与简单客数据库同步
- 📋 **订单管理** - 查看订单、发货、取消
- 🔥 **促销管理** - 创建和管理促销活动
- 📊 **数据分析** - 销售统计、商品排名
- 🔗 **SKU匹配** - 自动匹配库存商品
